# Bugzap

Pin-drop feedback for websites. Someone clicks anything on a page, a pin drops there, and a report goes out with the URL, the element under the pin, the viewport, and a screenshot, so nobody has to describe where the problem is.

Built for Routeloop and every other Feral Creative project: a small embeddable script that posts each report to whatever endpoint the host site configures, plus a hosted backend for sites with no feedback system of their own.
